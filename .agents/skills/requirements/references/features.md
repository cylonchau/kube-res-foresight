# 01 功能需求说明（中文）

> 来源：根目录 `docs/01-功能需求.md`。本文件为规划需求，现有代码能力及冲突处理以 [代码地图](repository-map.md) 和 [融合约定](integration-decisions.md) 为准；不代表页面已经实现。

## 1. 范围
单集群、预测算法平台、CPU/Memory 资源推荐与准入改写、自定义 CRD 副本自动伸缩、Platform Prometheus Metrics、历史预测准确率及扩缩容审计。保留系统管理已有模块；本期不含多云/跨集群迁移，也不替换 Kubernetes Scheduler/Karpenter。

## 2. 菜单和页面

系统设置、认证授权、用户、角色、权限、菜单及操作日志直接复用现有系统，不重建管理模块。下表按业务能力描述，不要求改变当前 system/authorization 菜单分组；新预测功能通过既有菜单、按钮和 API 权限机制增量接入。数据库统一沿用 GORM，兼容 SQLite、MySQL、PostgreSQL。
| 一级菜单 | 二级菜单 | 核心功能 |
|---|---|---|
| 总览 | 运行概览 | 工作负载、实时/预测 CPU/内存/RPS、Ready/目标副本数、模型健康、告警、回退状态、近期决策 |
| 系统管理 | 系统参数 | 持久化平台参数、采集周期、限额、安全开关、默认值、服务状态 |
| 系统管理 | 授权管理 | 用户、角色、菜单；认证方式、Token/会话策略；LDAP/LDAPS 与组角色映射在“系统参数”的 LDAP 分类中配置 |
| 系统管理 | 用户管理 | 本地/LDAP 用户、禁用、查看、检索、归属组织 |

## 3. LDAP 认证（系统参数中的 LDAP 分类）
支持 OpenLDAP、AD 及通用 LDAPv3：LDAPS/StartTLS、CA 验证、Bind DN 凭据 Secret、用户 Search Base/Filter、Group Base/Filter、用户属性映射、组角色映射、登录同步、禁用、连接测试、失败审计。本地 break-glass 超管保留；权限矩阵至少覆盖读、写、批准 Auto、解除 bypass、下载审计、编辑凭据；登录日志/操作日志分开。

## 4. 数据源与特征
默认数据源 Prometheus，支持多个数据源注册但每条指标映射必须选定来源。读取 30 天及其他自定义窗口历史数据；采用 HTTP API 查询、任务队列、分页/分段采样，限流与缓存；监控数据延迟、NaN、缺样、反常跳变和采样精度。指标聚合对象层级：cluster → namespace → workload → container/pod；RPS 可只有 Service 级，明确记录粒度，不得凭平均值伪造单 Pod RPS。

## 5. 模块管理
模块定义字段：模块 ID/名称/描述/标签、Namespace/Workload/Container 匹配、启用状态、模式 observe/recommend/admission/auto、数据源、特征、算法列表、参数覆盖、计算间隔、预测 horizon、推荐有效期、固定 fallback 规格、最小最大副本硬边界、资源上下界、风险等级、历史回测选择、审计追踪。
模块支持 **多个算法绑定**，每个算法可定制权重、优先级、触发条件、输入指标及运行频率。算法失败→候补算法；全部失败或数据不够→**返回模块的固定默认值**（不是最近一次未经验证的计算值）。同时展示默认值使用原因。

## 6. 特殊周期覆盖
管理员可以配置：2026-10-01 00:00 到 2026-10-20 23:59:59（示例、按配置时区）固定 10 副本、CPU Limit 6 核、Memory Limit 24Gi，并显式设置 CPU/Memory Request（若未设置不得自动猜值；采用模块已验证的默认 Requests）。可定义每日/每周周期与一次性日期窗。匹配时不计算覆盖字段的算法输出，直接返回规则固定值；记录覆盖依据。冲突按数值优先级、明确起止、规则 ID 稳定排序；保存时检测冲突。到期自动恢复算法或默认模式。必须区分每 Pod 资源值与工作负载副本总数。

## 7. 计算与执行
计算任务针对所有启用模块按计划取历史数据→特征→多算法→模型评分/选择→安全校验→生成版本化 recommendations；实时任务发布副本目标给 kubeforecast-operator，准入时 Webhook 使用预先保存的资源快照。启动/停止/重试/手工回放/对比/导出、幂等、超时、优先级、任务配额都需要支持。

## 8. Metrics
Platform Metrics 暴露每模块预测 RPS、CPU/Memory 需求、建议副本、默认与特殊周期命中、推荐年龄、模型可用性、MAE/WAPE、预测命中率、实际副本、目标副本、动作次数与原因。Metrics 是观测接口，不代替 Kubernetes Scale API 写入；Operator 可读取**直接内部快照**，无须依赖 Prometheus 先抓取再读回。

## 9. 非功能
多租户隔离；最小 RBAC；服务高可用；Webhook 超时/故障不阻塞发布；模型版本可回滚；至少 30 天原始指标回放可配置；审计保留期可配置；不允许爆炸式 Prometheus Label 基数；不把用户密钥写入日志；所有重要决策可解释、可追踪、可复现。

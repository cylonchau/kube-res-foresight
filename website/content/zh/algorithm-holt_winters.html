用途与适用负载

分离水平、趋势和季节变化。支持加性或乘性季节，以及阻尼趋势，适合有周期且水平缓慢变化的负载。

历史数据与运行条件

有季节项时至少两个完整周期；没有季节项时至少 4 个点。

输入应是等间隔、无缺口且数值有限的序列。输出保留输入指标单位，例如 CPU 核、内存字节或每秒请求数；采样步长决定步数对应的真实时间。最低样本数仅表示可运行，不代表预测可靠。

此方法不使用协变量；分别预测各目标指标。

原理与公式

Holt-Winters 是指数平滑（ETS）家族：把序列拆成“水平 ℓ”、可选的“趋势 b”和可选的“季节 s”三部分，每来一个新观测，就用平滑系数更新这三部分，预测时再把它们合起来。

令 base(t) = ℓ(t−1) + φ·b(t−1)                       （φ = 阻尼系数；不阻尼时 φ = 1）

无季节：   ŷ(t) = base(t)
加性季节： ŷ(t) = base(t) + s(t mod m)
乘性季节： ŷ(t) = base(t) × s(t mod m)

更新（e 为观测值）：
  水平  ℓ(t) = α·(y(t) − s) + (1−α)·base(t)              乘性时 y(t)/s 代替 y(t)−s
  趋势  b(t) = β·(ℓ(t) − ℓ(t−1)) + (1−β)·φ·b(t−1)       （开启 trend 时）
  季节  s(t mod m) = γ·(y(t) − ℓ(t)) + (1−γ)·s(t mod m)  乘性时 γ·y(t)/ℓ(t)

向前 h 步：  ŷ(T+h) = ℓ(T) + (φ + φ² + … + φʰ)·b(T)    再加上（或乘上）对应位置的季节项

参数怎样进入公式：

  • alpha、beta、gamma：水平、趋势、季节的平滑系数，0 到 1，越大越快跟随新数据。填 0 表示自动选择：在一个小网格上试（alpha ∈ {0.1, 0.3, 0.5, 0.7, 0.9}，beta ∈ {0.01, 0.1, 0.3}，gamma ∈ {0.1, 0.3, 0.5}），取历史上一步预测误差平方和最小的组合。
  • trend：是否带趋势项 b。damped 与 damping_phi：趋势是否阻尼，φ 默认 0.98；阻尼后趋势每向前一步乘一次 φ，预测不会无限上冲。
  • season_length_steps（m）与 seasonal_mode：季节长度（步数）和加性/乘性。m 为 0 表示不带季节；带季节时至少要有 2m 个点。乘性季节要求历史全部大于 0，碰到 0 会拒绝，而不是悄悄改数据。
  • non_negative：预测小于 0 时截为 0。

为什么这样做：水平、趋势、季节分别用自己的系数更新，所以能同时跟上“缓慢抬升”和“每天的起伏”，而且一遍扫描就能算完，没有训练。乘性季节适合“负载越高、日内波动越大”的资源；加性季节适合波动幅度基本固定的。

初始化：带季节时，水平取第一个周期的平均，趋势取前两个周期平均的差除以 m，季节项取第一个周期各点相对平均的差（或比）；不带季节时，水平取第一个值，趋势取最前 10 个点（不足 10 个就用全部）的最小二乘斜率，避免一个噪声点决定起始趋势。

以第 1 行为例：base = 10 + 1.0286 = 11.0286；ℓ = 0.5×10 + 0.5×11.0286 = 10.5143；b = 0.3×(10.5143 − 10) + 0.7×1.0286 = 0.8743。

预测：最后的状态是 ℓ = 15.0859、b = 0.9260，不阻尼，所以

ŷ(T+1) = 15.0859 + 1×0.9260 = 16.0119
ŷ(T+2) = 15.0859 + 2×0.9260 = 16.9379
ŷ(T+3) = 15.0859 + 3×0.9260 = 17.8639

结果 [16.0119, 16.9379, 17.8639]：沿着最近的趋势每步多约 0.93。如果打开 damped（φ=0.98），增量变成 0.926×(0.98 + 0.98² + 0.98³)，增长会逐步放缓，长预测范围内不会一直上冲。

这些数字由 pkg/forecast/docs_examples_test.go 用真实代码算出并持续校验。

调参与取舍

先使用自动平滑系数（0）。需要抑制远期趋势时开启 damped。multiplicative 要求周期至少 2 且历史严格大于 0，含零值时改用 additive。

通用参数：变化重置与分位校准

参数 / 类型默认值 / 范围 / 单位含义与使用
reset_on_change
bool		false
无额外范围限制		水平突变后重置：检测历史里最后一次水平突变（发布、扩缩容、流量切换），只用突变之后的历史预测。关闭时用全部历史（现状）。突变之后至少要有 6 步才会被确认；突变后的历史不够算法所需时，取算法所需的最新一段。
change_threshold
float		8
≥ 3; ≤ 50		突变阈值：突变幅度（扣除前一段趋势后）超过噪声的多少倍才算，越大越不容易误报，噪声由相邻步变化的稳健标准差估计。仅 reset_on_change=true 时使用。
change_min_shift
float		0.2
≥ 0; ≤ 5		最小突变幅度：突变至少是水平的这个比例（0.2 = 20%），很干净的序列上的微小跳变不算。仅 reset_on_change=true 时使用。
quantile_level
float		0
≥ 0; ≤ 0.99		推荐分位数：0 = 点预测（现状）；0.9 等 = 预测「实际值有约 90% 的把握不超过」的线（保形预测：用本算法在这个负载最近几个窗口里的真实误差校准，需要更多历史和时间）。必须大于 0.5。
calibration_windows
int		8
≥ 3; ≤ 50		校准窗口数：用最近多少个历史窗口测本算法的误差；越多越稳，也越慢（每个窗口多跑一次预测）。仅推荐分位数大于 0 时使用。

quantile_level 是 0～1 的分位点，percentile 是 1～100 的百分数，二者不是同一参数。分位校准会额外运行历史预测；增加校准窗口前检查历史与运行预算，覆盖率是评估目标而非保证。

在模块中使用

  1. 保存参数，检查历史窗口、采样步长和预测范围。
  2. 打开模块的“启用预测”；固定算法只运行指定方法，动态算法使用平台已启用的方法。
  3. 先运行滚动回测，通过版本晋升后才会采用；修改影响模型版本的参数后重新回测。
  4. 在仅观察或仅推荐下检查误差、峰值低估、耗时与采用原因，再分别授权准入和副本执行。

历史不足、参数不合法、运行超时或输出无效时，检查算法运行原因；没有合格预测时按模块的固定周期、兜底与保护规则处理。

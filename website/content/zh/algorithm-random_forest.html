用途与适用负载

对抽样后的历史特征训练多棵回归树并平均，支持非线性关系与协变量。训练成本高于简单统计方法。

历史数据与运行条件

至少 lags + 4×min_samples_leaf + 1 点；训练窗口仍需保留足够样本。

输入应是等间隔、无缺口且数值有限的序列。输出保留输入指标单位，例如 CPU 核、内存字节或每秒请求数；采样步长决定步数对应的真实时间。最低样本数仅表示可运行，不代表预测可靠。

支持协变量：使用同一时间网格上的其他指标，特征仅取预测起点之前的值；未来协变量沿用最后观测值，不是假设已知未来业务量。

原理与公式

随机森林是许多棵回归树的平均。每棵树只看一个随机抽样的训练子集和一个随机的特征子集，所以每棵树都不完美，但彼此犯的错不同，平均起来比单棵稳。特征是前几步的值、可选的日历特征和协变量；预测时递归向前滚。

特征：    x(t) = [ y(t−1), …, y(t−L) ] （+ 日历 sin/cos，+ 协变量滞后）            L = lags
每棵树 b = 1 … B（B = n_estimators）：
  1) 从训练行里有放回地抽 sample_ratio × 行数 行（自助采样）
  2) 随机抽 feature_ratio × 特征数 个特征，这棵树只能用它们分裂
  3) 在抽到的行上递归分裂：把特征值按 32 个分箱，选使“方差减小量”最大的 (特征, 分箱边界)，
       gain = (ΣL)²/nL + (ΣR)²/nR − (Σ)²/n          Σ 是该侧目标值之和，n 是行数
     直到深度达到 max_depth，或一侧的行数少于 min_samples_leaf；叶子的值 = 该叶里目标值的平均
预测：    ŷ(t) = (1/B) · Σ tree_b( x(t) )
多步：    把预测当作下一步的滞后值，递归向前滚

参数怎样进入公式：

  • lags（L）：用前几步作特征，必须选。
  • n_estimators（B）：树的数量。越多越稳、越慢（默认 50）。
  • max_depth：每棵树的最大深度（默认 6）。越深越能拟合复杂关系，也越容易记住噪声。
  • min_samples_leaf：叶子至少几行（默认 5）。越大越平滑。最少样本数 = lags + 4×min_samples_leaf + 1。
  • feature_ratio、sample_ratio：每棵树用多少比例的特征、多少比例的行（有放回）。比例小则树之间更不一样。
  • seed：随机种子。种子固定时，同样的历史和参数永远给出同样的预测（可复现）。
  • calendar_features、covariate_lags、training_window_steps：同 岭回归自回归。

为什么这样做：树模型能拟合非线性关系（比如“上一步低于某个值时下一步会回升”），不需要对数据做线性假设，也不怕特征量纲不同。多棵树平均，用来抵消单棵树的过拟合。

关键限制：树模型不能外推。叶子的值是训练目标的平均，所以预测永远落在训练目标的取值范围内。负载持续上升到历史从没见过的高度时，它不会预测更高。这是平台要求它在回测里胜过基线才会被采用的原因，也是它更适合“在已见范围内波动”的负载，而不是增长中的负载。

计算示例：数据、参数与代入过程

用一个最简单的“一直上升”的序列来看“不能外推”：每 5 分钟一个点，从 10 一直升到 29（每步加 1），共 20 个点。

{
  "lags": 2,
  "n_estimators": 20,
  "max_depth": 3,
  "min_samples_leaf": 2,
  "feature_ratio": 1,
  "sample_ratio": 1,
  "seed": 42
}
y = [10, 11, 12, …, 28, 29]        n = 20；训练行：特征 [y(t−1), y(t−2)]，目标 y(t)，共 18 行，目标范围 12 … 29

按“每步加 1”，下一步人人都知道应该是 30、31、32。但随机森林给出的是：

ŷ = [27.9125, 27.9125, 27.9125]

三个预测都低于历史里的最大值 29，而且是一条水平线。原因：

  • 预测第 1 步时，特征 [29, 28] 落在每棵树“最大特征值那一侧”的叶子里；叶子的值是该叶训练目标的平均，而训练目标最大是 29，所以预测不可能超过 29。
  • 这个预测 27.9 又被当作下一步的滞后值，落进同一片叶子，所以后面各步还是 27.9。

对比：同样的数据，线性模型（岭回归自回归）（默认参数）预测约 29.95、30.92、31.88，一直往上。因此，对在增长的负载，要留意树模型会偏低；它在负载围绕一个范围起伏、关系是非线性的时候才占优。

森林内部的一次分裂怎么选，见 GBDT 页的示例，那里把每一步（基线值、残差、分裂的增益、叶子的值）都列了出来；随机森林的树用同样的分裂规则，只是拟合目标本身而不是残差，并且每棵树只在抽样后的行和特征上分裂。

这些数字由 pkg/forecast/docs_examples_test.go 用真实代码算出并持续校验（随机种子固定为 42，所以结果可复现）。

调参与取舍

先限制树数、深度与训练窗口。增加树数提高开销，增加深度更容易拟合噪声；seed 用于可重复比较。与岭回归和基线使用相同回测窗口比较。

通用参数：变化重置与分位校准

参数 / 类型默认值 / 范围 / 单位含义与使用
reset_on_change
bool		false
无额外范围限制		水平突变后重置：检测历史里最后一次水平突变（发布、扩缩容、流量切换），只用突变之后的历史预测。关闭时用全部历史（现状）。突变之后至少要有 6 步才会被确认；突变后的历史不够算法所需时，取算法所需的最新一段。
change_threshold
float		8
≥ 3; ≤ 50		突变阈值：突变幅度（扣除前一段趋势后）超过噪声的多少倍才算，越大越不容易误报，噪声由相邻步变化的稳健标准差估计。仅 reset_on_change=true 时使用。
change_min_shift
float		0.2
≥ 0; ≤ 5		最小突变幅度：突变至少是水平的这个比例（0.2 = 20%），很干净的序列上的微小跳变不算。仅 reset_on_change=true 时使用。
quantile_level
float		0
≥ 0; ≤ 0.99		推荐分位数：0 = 点预测（现状）；0.9 等 = 预测「实际值有约 90% 的把握不超过」的线（保形预测：用本算法在这个负载最近几个窗口里的真实误差校准，需要更多历史和时间）。必须大于 0.5。
calibration_windows
int		8
≥ 3; ≤ 50		校准窗口数：用最近多少个历史窗口测本算法的误差；越多越稳，也越慢（每个窗口多跑一次预测）。仅推荐分位数大于 0 时使用。

quantile_level 是 0～1 的分位点，percentile 是 1～100 的百分数，二者不是同一参数。分位校准会额外运行历史预测；增加校准窗口前检查历史与运行预算，覆盖率是评估目标而非保证。

在模块中使用

  1. 保存参数，检查历史窗口、采样步长和预测范围。
  2. 打开模块的“启用预测”；固定算法只运行指定方法，动态算法使用平台已启用的方法。
  3. 先运行滚动回测，通过版本晋升后才会采用；修改影响模型版本的参数后重新回测。
  4. 在仅观察或仅推荐下检查误差、峰值低估、耗时与采用原因，再分别授权准入和副本执行。

历史不足、参数不合法、运行超时或输出无效时，检查算法运行原因；没有合格预测时按模块的固定周期、兜底与保护规则处理。

用户、角色与权限

通过用户、角色、菜单和 API 权限分配访问范围。区分查看结果、修改策略和授权执行，机器凭据按用途配置最小权限。

目录认证

在系统管理 → 系统参数的 LDAP 分类中配置连接、用户和组查询、角色映射、连接检查与同步。支持 LDAPS / StartTLS 配置；本地账号保留本地认证，作为目录不可用时的应急入口。

任务与全局设置

任务中心管理周期任务、调度和执行记录。失败后先核对输入与错误，再处理重试。全局参数维护安全开关、前瞻决策和默认配置，模块负责各工作负载自己的边界与策略。

存储与显示时区

时间存储使用 UTC。平台默认时区为 UTC+8，可通过 KUBE_RESOURCE_FCST_TIMEZONE 配置，作用于日志、数据库会话与新模块周期；页面固定按 UTC+8 显示，不跟随浏览器时区。调度区间仍按显式 IANA 时区解释。

日志、保留与导出

登录日志记录认证行为，操作日志记录配置和导出等操作。推荐、执行、准入和降级记录帮助解释资源变化。按复盘周期设置保留要求，备份数据库及稳定的凭据加密密钥。

控制历史保留与准入记录量

通过系统参数 forecast.history_retention_days 统一配置历史保留天数；默认 0 使用各类记录内置保留周期。forecast.evaluation_max_per_module 默认每模块保留最新 20,000 条实测评估，最少 100 条。

准入调用需携带 request_uid 才生成记录，并按 UID 去重。具备工作负载版本信息时，默认记录创建及每个新版本的首个 Pod；扩容和替换产生的后续 Pod 仍正常处理，但不逐一记录。需要完整记录时启用 forecast.admission_record_scaling。有请求 UID、没有版本信息时继续逐次记录。

AI 配置与通知

系统参数 assistant.enabled 控制聊天入口；“AI 配置”分别管理 LLM 连接、Skill 与 定时任务。LLM、Skill、任务菜单和 assistant:chat 权限分别授予。

邮件使用系统参数通知分类的 notify.email.* 配置。接入前同时检查模型连接、邮箱与 SMTP，定时任务运行结果在任务中心与任务记录中查看。

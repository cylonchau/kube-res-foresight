System overview

kube-res-foresight connects collection, forecasting, recommendations, and controlled actions for one Kubernetes cluster. Follow blue data relationships to see how advice is produced, then green control relationships to see where it is applied.

Prometheus scrapes workload and cluster metrics. The platform actively queries its HTTP API for history and recent samples. Metric arrows represent data relationships, not direct pushes from applications. Observed usage and Ready replicas return to collection and evaluation.

Dashed relationships are optional: time-series services produce numerical forecasts, while the AI assistant provides querying and analysis. Boxes represent responsibilities, not necessarily separate deployments.

The console manages these capabilities through Platform APIs. Platform and task entry points share business rules and a database and can be combined according to deployment needs. Logical modules do not require separate services.

Two independent execution paths

New Pod resources: API Server admission invokes Kyverno, whose policy queries validated, unexpired resource advice and applies authorized requests and managed limits. Admission does not wait for collection, inference, or long queries. Unavailable advice preserves original resources.

Workload replicas: the Operator reads modules and decisions from the platform, checks bounds, readiness, cooldown, and step limits, then writes replicas through the Kubernetes Scale API. It neither reads the platform database nor changes Pod requests/limits.

Authorize the paths separately. Only one controller may write a workload's replicas; the Operator and HPA/KEDA cannot control the same target simultaneously. Updated recommendations do not immediately resize running Pods.

Feedback and observability

Platform and Operator expose Prometheus metrics for monitoring, including with Grafana. Management views relate forecasts, advice, reported actions, admissions, and measured effectiveness. Execution does not wait for Prometheus to scrape decisions and read them back.

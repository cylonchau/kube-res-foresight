使用指南

GBDT · 梯度提升树

逐棵拟合残差，学习滞后、日历与协变量的非线性关系。可预测均值附近的点值，也可直接训练分位数目标。

← 算法与模型总览

用途与适用负载

逐棵拟合残差，学习滞后、日历与协变量的非线性关系。可预测均值附近的点值，也可直接训练分位数目标。

历史数据与运行条件

至少 lags + 4×min_samples_leaf + 1 点；direct 模式再增加 horizon−1 点。

输入应是等间隔、无缺口且数值有限的序列。输出保留输入指标单位，例如 CPU 核、内存字节或每秒请求数；采样步长决定步数对应的真实时间。最低样本数仅表示可运行，不代表预测可靠。

支持协变量：使用同一时间网格上的其他指标，特征仅取预测起点之前的值；未来协变量沿用最后观测值，不是假设已知未来业务量。

原理与公式

GBDT（梯度提升回归树）是一棵接一棵地加树：先用一个常数当起点，每加一棵新树，就去拟合“当前预测还差多少”（残差），再把这棵树按学习率的一小部分加进总预测。特征是前几步的值、可选的日历特征和协变量；预测时递归向前滚（或每个锚点步训练一组树）。

公式
起点：    F₀ = 训练目标的平均值（objective = quantile 时取 alpha 分位数）
第 m 棵树（m = 1 … M，M = n_estimators）：
  残差   r(i) = y(i) − F(m−1)(x(i))                     （quantile 目标时，要拟合的“梯度”是 alpha 或 alpha−1，叶子取残差的 alpha 分位数）
  分裂   把特征值分成 32 箱，选使增益最大的 (特征, 分箱边界)：
           gain = (ΣL)²/nL + (ΣR)²/nR − (Σ)²/n           Σ 是该侧残差之和，n 是行数
         递归到深度 max_depth，或一侧行数少于 min_samples_leaf；叶子的值 = 该叶残差的平均
  更新   F(m)(x) = F(m−1)(x) + learning_rate × tree_m(x)
预测：    ŷ(t) = F(M)( x(t) )，多步递归：把预测当作下一步的滞后值

参数怎样进入公式：

  • lags：前几步作特征，必须选；calendar_features、covariate_lags、training_window_steps 同岭回归自回归。
  • n_estimators（M）：树的数量（默认 100）。
  • learning_rate：每棵树贡献的比例（默认 0.1）。小一点需要更多棵树，但更不容易过拟合。
  • max_depth、min_samples_leaf：同随机森林。最少样本数 = lags + 4×min_samples_leaf + 1。
  • objective：squared 是平方误差的点预测；quantile 用 pinball 损失预测 alpha 分位数（例如 0.9 = 实际值约 90% 的时候不超过它），用于峰值或容量保护，需要单独验证覆盖率。
  • multi_step、direct_anchors：递归或直接多步，同岭回归自回归。

为什么这样做：每棵树都很浅，单独看很弱；一棵接一棵拟合残差，让总预测一步步逼近目标。这样既能表达非线性关系，又比一棵深树更不容易过拟合。分位数目标让它能直接预测“偏保守”的线，适合容量保护。

限制：和所有树模型一样，GBDT 不能外推，预测落在训练目标的范围之内（见 随机森林页的例子）。这里的树是确定的，没有抽样，同样的历史总给出同样的预测。

配置示例

在“算法管理”编辑参数。以下仅为参数对象，不是 config.yaml 全文；周期示例按 5 分钟采样，需按实际步长调整。未列出的可选参数使用上表默认值。

JSON
{
  "lags": 24,
  "n_estimators": 100,
  "learning_rate": 0.1,
  "max_depth": 3,
  "training_window_steps": 5000,
  "multi_step": "recursive",
  "objective": "squared"
}

计算示例：数据、参数与代入过程

为了把每一步都列出来，用最小的设置：2 个滞后值，1 棵深度为 1 的树（只分裂一次），学习率 0.5。

JSON
{
  "lags": 2,
  "n_estimators": 1,
  "learning_rate": 0.5,
  "max_depth": 1,
  "min_samples_leaf": 1,
  "objective": "squared"
}
数据
y = [10, 12, 13, 15, 14, 16, 18, 17, 19, 21]        每 5 分钟一个点，预测 2 步

第 1 步，训练样本与起点。8 行，目标的平均值 F₀ = (13+15+14+16+18+17+19+21)/8 = 16.625。每行的残差 r = y − 16.625：

特征 y(t−1)特征 y(t−2)目标 y(t)残差 r
121013−3.625
131215−1.625
151314−2.625
141516−0.625
161418+1.375
181617+0.375
171819+2.375
191721+4.375

第 2 步，找最好的一次分裂。在所有 (特征, 阈值) 里选增益最大的。最好的是“y(t−1) ≤ 15”：

计算
左侧（y(t−1) ≤ 15：四行 12、13、15、14）：残差和 = −3.625 −1.625 −2.625 −0.625 = −8.5，nL = 4
右侧（y(t−1) > 15：四行 16、18、17、19）：残差和 = +1.375 +0.375 +2.375 +4.375 = +8.5，nR = 4
总和 = 0，n = 8
gain = 8.5²/4 + 8.5²/4 − 0²/8 = 18.0625 + 18.0625 = 36.125

叶子的值是该叶残差的平均：左 = −8.5/4 = −2.125，右 = +8.5/4 = +2.125。

第 3 步，预测。要预测的下一点，特征是最后两个值：y(t−1) = 21，y(t−2) = 19。21 > 15，进入右叶，贡献 +2.125，乘学习率 0.5：

计算
ŷ(T+1) = F₀ + 0.5 × 2.125 = 16.625 + 1.0625 = 17.6875

第 4 步，递归。第 2 步的特征是 y(t−1) = 17.6875（也 > 15），仍然进右叶，所以 ŷ(T+2) = 17.6875。预测 [17.6875, 17.6875]。

两点值得注意：一是历史最后一个值是 21，预测却是 17.69，比最近的值低得多：只有一棵浅树，更接近“整体均值加一点调整”；二是学习率 0.5 让每棵树只贡献一半。把 n_estimators 改成 2，第二棵树去拟合第一棵之后的残差，第 1 步的预测变为 18.84375；树越多，预测越逼近训练数据的细节，也越容易过拟合。真实使用的默认是 100 棵、深度 3、学习率 0.1。

这些数字由 pkg/forecast/docs_examples_test.go 用真实代码算出并持续校验。

调参与取舍

learning_rate 越小通常需要更多树。alpha 只在 objective=quantile 时表示分位点，与 EWMA 的 alpha 不同。先单独比较原生分位目标或保形校准，避免无意叠加两层上偏。

来源与引用

  • Friedman, J.H. “Greedy function approximation: a gradient boosting machine”，The Annals of Statistics 29(5)，2001，1189–1232：梯度提升的原始论文。
  • Koenker, R. & Bassett, G. “Regression quantiles”，Econometrica 46(1)，1978，33–50：分位数回归与 pinball 损失。
  • Ke, G. 等 “LightGBM: A Highly Efficient Gradient Boosting Decision Tree”，NeurIPS 2017：把特征值分箱（直方图）来加速分裂的做法；本实现用 32 箱，是它的简化版，不依赖该库。
  • Breiman 等 Classification and Regression Trees（1984）：回归树与方差减小的分裂准则，同随机森林页。

通用参数：变化重置与分位校准

参数 / 类型默认值 / 范围 / 单位含义与使用
reset_on_change
bool		false
无额外范围限制		水平突变后重置：检测历史里最后一次水平突变（发布、扩缩容、流量切换），只用突变之后的历史预测。关闭时用全部历史（现状）。突变之后至少要有 6 步才会被确认；突变后的历史不够算法所需时，取算法所需的最新一段。
change_threshold
float		8
≥ 3; ≤ 50		突变阈值：突变幅度（扣除前一段趋势后）超过噪声的多少倍才算，越大越不容易误报，噪声由相邻步变化的稳健标准差估计。仅 reset_on_change=true 时使用。
change_min_shift
float		0.2
≥ 0; ≤ 5		最小突变幅度：突变至少是水平的这个比例（0.2 = 20%），很干净的序列上的微小跳变不算。仅 reset_on_change=true 时使用。
quantile_level
float		0
≥ 0; ≤ 0.99		推荐分位数：0 = 点预测（现状）；0.9 等 = 预测「实际值有约 90% 的把握不超过」的线（保形预测：用本算法在这个负载最近几个窗口里的真实误差校准，需要更多历史和时间）。必须大于 0.5。
calibration_windows
int		8
≥ 3; ≤ 50		校准窗口数：用最近多少个历史窗口测本算法的误差；越多越稳，也越慢（每个窗口多跑一次预测）。仅推荐分位数大于 0 时使用。

quantile_level 是 0～1 的分位点，percentile 是 1～100 的百分数，二者不是同一参数。分位校准会额外运行历史预测；增加校准窗口前检查历史与运行预算，覆盖率是评估目标而非保证。

在模块中使用

  1. 保存参数，检查历史窗口、采样步长和预测范围。
  2. 打开模块的“启用预测”；固定算法只运行指定方法，动态算法使用平台已启用的方法。
  3. 先运行滚动回测，通过版本晋升后才会采用；修改影响模型版本的参数后重新回测。
  4. 在仅观察或仅推荐下检查误差、峰值低估、耗时与采用原因，再分别授权准入和副本执行。

历史不足、参数不合法、运行超时或输出无效时，检查算法运行原因；没有合格预测时按模块的固定周期、兜底与保护规则处理。

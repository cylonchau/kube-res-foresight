使用指南

Naive · 持续值

将最后一个观测值延续到整个预测范围，作为所有候选的基本对照。适合检查数据与预测链路，不能提前识别周期或突增。

← 算法与模型总览

用途与适用负载

将最后一个观测值延续到整个预测范围，作为所有候选的基本对照。适合检查数据与预测链路，不能提前识别周期或突增。

历史数据与运行条件

至少 1 个有效观测值。

输入应是等间隔、无缺口且数值有限的序列。输出保留输入指标单位，例如 CPU 核、内存字节或每秒请求数；采样步长决定步数对应的真实时间。最低样本数仅表示可运行，不代表预测可靠。

此方法不使用协变量；分别预测各目标指标。

原理与公式

持续值（也叫随机游走预测）只做一件事：把最后一个观测值当作未来每一步的预测。

公式
ŷ(T+h) = y(T)        h = 1, 2, …, H

其中 y(T) 是历史里最新的一个值，H 是要预测的步数，h 是向前第几步。没有任何参数，也不训练。

为什么这样做：资源负载在几分钟到几十分钟内通常很“黏”，下一步最可能的值就是现在的值，所以这个最简单的预测在短时间范围内往往很难被击败。平台把它当作基线：任何更复杂的算法必须在回测里胜过它才有资格被采用；它也能用来检查数据采集和预测链路是否正常（它的曲线应该紧贴实际值、只是晚一步）。

它做不到的：看不见周期，也看不见即将到来的上涨或下降。负载一变，它会晚一个预测周期才跟上。

无算法专属参数，参数对象为 {}。

调参与取舍

没有算法参数。需要趋势或周期时，比较 EWMA、Theta 或季节持续，而不是为持续值增加额外参数。

来源与引用

  • Hyndman, R.J. & Athanasopoulos, G. Forecasting: Principles and Practice（第 3 版，OTexts，2021），第 5.2 节“一些简单的预测方法”中的 Naïve method：https://otexts.com/fpp3/simple-methods.html。
  • 把它作为所有候选的基线，是时间序列预测评估的通用做法：新方法要先证明比 naïve 更好才有意义（同一本书第 5.8 节评估预测准确性）。

在模块中使用

  1. 保存参数，检查历史窗口、采样步长和预测范围。
  2. 打开模块的“启用预测”；固定算法只运行指定方法，动态算法使用平台已启用的方法。
  3. 此方法为基线，无需回测晋升，但仍应比较实测表现。
  4. 在仅观察或仅推荐下检查误差、峰值低估、耗时与采用原因，再分别授权准入和副本执行。

历史不足、参数不合法、运行超时或输出无效时，检查算法运行原因；没有合格预测时按模块的固定周期、兜底与保护规则处理。

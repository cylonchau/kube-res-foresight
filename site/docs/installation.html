文档/开始使用

使用指南

安装与部署

准备管理平台、任务引擎与执行组件，了解配置和启动方式。

准备哪些组件

管理平台提供控制台、数据管理、预测和推荐；任务引擎负责周期运行。需要调整集群副本时部署 Operator，需要为新 Pod 应用资源建议时配置准入策略。

组件用途
Platform管理界面、API、指标、预测与推荐。
Job engine采集、预测、回测、评估等周期任务，可与平台一起运行。
Operator按授权和边界调整目标工作负载的副本。
资源准入使用有效资源建议处理新 Pod 的 requests / limits。

构建管理平台

准备仓库声明的 Go、Node.js 与 pnpm 工具链。管理前端 web/ 是独立仓库，构建前需要准备好其源码。

Bash
cd web
pnpm install --frozen-lockfile
cd ..
make package-web
mkdir -p target/bin
go build -o target/bin/kube-resource-fcst ./cmd

配置与启动

参考 config.yaml 配置数据库、监听地址、日志和稳定的 JWT 密钥。数据库支持 SQLite、MySQL、PostgreSQL。环境变量使用 KUBE_RESOURCE_FCST_ 前缀，凭据加密密钥使用 KUBE_RESOURCE_FCST_SECRET_KEY。

Bash
# 首次安装：显式迁移
target/bin/kube-resource-fcst server --config config.yaml --migration

# 启动管理平台与任务引擎
target/bin/kube-resource-fcst all --config config.yaml

示例服务端口为 20001，启动后访问 http://localhost:20001。也可分别运行 server 与 job。

已有安装与执行组件

保留已有数据库连接、路径及密钥值。升级前先备份，再审阅 --upgrade 的清理范围；普通启动不执行退役表清理。

Operator 与准入需要目标集群权限、凭据、证书及相应策略。先保持观察模式，检查资源引用和副本所有权，再开放执行。

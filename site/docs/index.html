算法参数手册

Naive · 持续值

将最后一个观测值延续到整个预测范围，作为所有候选的基本对照。适合检查数据与预测链路，不能提前识别周期或突增。

Seasonal Naive · 季节持续

重复前一个周期对应位置的值，用于规律重复的负载，也是周期模型的比较基线。前一周期的异常会被重复。

EWMA · 指数平滑

平滑近期波动后将水平延续到未来。适合作为低成本、重视近期负载的候选，不会直接外推日周期。

Histogram Percentile · 历史分位数

对带时间衰减的历史取百分位，并将该值作为未来各步的水平。适合关注资源高水位的规格比较，不刻画峰值发生的具体时刻。

Random Forest · 随机森林

对抽样后的历史特征训练多棵回归树并平均，支持非线性关系与协变量。训练成本高于简单统计方法。

KNN · 历史相似窗口

寻找与当前窗口相似的历史片段，参考其后续轨迹。适合历史中曾出现过的峰谷形态，不擅长没有历史先例的新变化。

Holt-Winters · 趋势与季节

分离水平、趋势和季节变化。支持加性或乘性季节，以及阻尼趋势，适合有周期且水平缓慢变化的负载。

模型服务 · 预测与微调

通过 HTTP 调用外部时序模型。模型管理中配置服务，模块中选择预测方式。服务不可用时本次候选失败，其他算法继续按资格参与。

Theta · 平滑与漂移

将平滑水平与线性趋势斜率的一半结合，支持先去季节。适合作为带噪声趋势序列的候选，预测下限为 0。

MSTL · 多重季节分解

同时分离日、周季节形状，对去季节后的序列使用 Theta。本项目采用固定季节形状的迭代分解，不是随时间变化的 LOESS 分解。

Seasonal Profile · 周期画像

按一天中的时段和周几分桶，对每个桶取衰减百分位。适合“工作日上午忙、周末安静”等有时钟规律的负载。

Peak Envelope · 峰值包络

先计算滚动最大值包络，再用稳健斜率外推，关注高水位而非平均值。适合内存锯齿、缓存增长等形态。

Combination · 组合预测

对多个成员的预测逐步取中位数，或按近期误差加权。组合本身也需要回测晋升，不默认优于单个成员。

Ridge AR · 岭回归自回归

用滞后值、可选 UTC 日历特征与协变量拟合线性关系。适合稳定的线性依赖，作为低成本机器学习候选。

GBDT · 梯度提升树

逐棵拟合残差，学习滞后、日历与协变量的非线性关系。可预测均值附近的点值，也可直接训练分位数目标。

EWMA · 指数平滑

平滑近期波动后将水平延续到未来。适合作为低成本、重视近期负载的候选，不会直接外推日周期。

← 算法与模型总览

用途与适用负载

平滑近期波动后将水平延续到未来。适合作为低成本、重视近期负载的候选，不会直接外推日周期。

历史数据与运行条件

至少 2 个点。

输入应是等间隔、无缺口且数值有限的序列。输出保留输入指标单位，例如 CPU 核、内存字节或每秒请求数；采样步长决定步数对应的真实时间。最低样本数仅表示可运行，不代表预测可靠。

此方法不使用协变量；分别预测各目标指标。

原理与公式

EWMA（指数加权移动平均，也叫简单指数平滑）给每个历史值一个权重，越新的权重越大，权重按固定比例逐步衰减；预测是平滑后的“当前水平”，向未来水平延续。

公式
水平递推：  ℓ(1) = y(1)
            ℓ(t) = α·y(t) + (1 − α)·ℓ(t−1)        t = 2 … T
预测：      ŷ(T+h) = ℓ(T)                          h = 1 … H（一条水平线）

等价地：ℓ(T) = α·Σ (1−α)^k · y(T−k)，最新值权重 α，往前每一步乘 (1−α)

参数怎样进入公式：

  • alpha（α，0 到 1）：越大越看重最新值。有效“记忆长度”约为 1/α 步：α=0.3 约相当于看最近 3 步多一点。
  • span：另一种写法，α = 2 / (span + 1)。span=5 等价于 α=1/3。两者只能选一个。
  • bias_correction：把权重 (1−α)^龄 直接加权求平均，再除以权重之和，而不是从第一个值起递推。历史很短时，第一个值不会拖着结果。

为什么这样做：实测负载有噪声，直接取最后一个值会被一次毛刺带偏，取全部历史的平均又反应太慢。EWMA 用一个参数在“跟得上”和“抗噪声”之间取舍，计算只有一个循环，几乎没有成本，所以适合作为低成本候选，特别是重视近期负载的场景。

它做不到的：预测是一条水平线，既不外推趋势，也不认识周期。负载持续上升时它总是偏低一截（落后于趋势）。

参数说明

窄屏可左右滑动参数表，查看完整说明。

参数 / 类型默认值 / 范围 / 单位含义与使用
alpha
float		0.3
≥ 0.001; ≤ 1		平滑系数，越大越贴近最新值；取值 (0,1]。与 span 二选一。
span
int		0
≥ 0; ≤ 100000; steps		用跨度表示平滑：alpha = 2/(span+1)。0 表示不使用，改用 alpha；两者不能同时给出。
bias_correction
bool		false
无额外范围限制		偏差修正：按 (1-alpha)^龄 加权后除以权重和，而不是以第一个观测值起算，短历史上更不受首个值影响。

配置示例

在“算法管理”编辑参数。以下仅为参数对象，不是 config.yaml 全文；周期示例按 5 分钟采样，需按实际步长调整。未列出的可选参数使用上表默认值。

JSON
{
  "alpha": 0.3,
  "bias_correction": false
}

计算示例：数据、参数与代入过程

最近 6 个采样点（每 5 分钟一个）的 CPU 使用量（核）。参数：

JSON
{
  "alpha": 0.3,
  "bias_correction": false
}
数据
y = [10, 12, 11, 15, 14, 16]

按公式从第一个值起递推，ℓ(t) = 0.3·y(t) + 0.7·ℓ(t−1)：

ty(t)代入ℓ(t)
110ℓ(1) = y(1)10.0000
2120.3×12 + 0.7×10.000010.6000
3110.3×11 + 0.7×10.600010.7200
4150.3×15 + 0.7×10.720012.0040
5140.3×14 + 0.7×12.004012.6028
6160.3×16 + 0.7×12.602813.6220

所以预测是 [13.622, 13.622]（取 2 步）：一条水平线。注意最后一个实际值是 16，预测却是 13.6，因为前面较小的值仍在拉低它，这就是“平滑”的代价，也是它在上升负载里偏低的原因。

改参数看看结果怎么变（同样的数据）：

  • bias_correction: true：直接用权重 1、0.7、0.49、0.343、0.2401、0.16807（最新的值权重最大）加权平均，得到 14.1049。它不再受第一个值 10 的牵连，所以更高。
  • span: 5（α = 2/6 ≈ 0.3333）：得到 13.8601，比 α=0.3 稍微更贴近最新值。

这些数字由 pkg/forecast/docs_examples_test.go 用真实代码算出并持续校验。

调参与取舍

alpha 越大越快跟随最近变化，也越容易受噪声影响。span 是另一种指定平滑强度的方式；显式 alpha 与正数 span 不能同时填写。

来源与引用

  • Brown, R.G. Statistical Forecasting for Inventory Control（McGraw-Hill，1959）：指数平滑方法的经典来源。
  • Hyndman, R.J. & Athanasopoulos, G. Forecasting: Principles and Practice（第 3 版，OTexts，2021），第 8.1 节简单指数平滑：https://otexts.com/fpp3/ses.html。
  • Hyndman, R.J. 等 Forecasting with Exponential Smoothing: The State Space Approach（Springer，2008）：指数平滑的统一理论。
  • span 与 α 的换算 α = 2/(span+1) 沿用 pandas 的 ewm(span=…) 约定。

通用参数：变化重置与分位校准

参数 / 类型默认值 / 范围 / 单位含义与使用
reset_on_change
bool		false
无额外范围限制		水平突变后重置：检测历史里最后一次水平突变（发布、扩缩容、流量切换），只用突变之后的历史预测。关闭时用全部历史（现状）。突变之后至少要有 6 步才会被确认；突变后的历史不够算法所需时，取算法所需的最新一段。
change_threshold
float		8
≥ 3; ≤ 50		突变阈值：突变幅度（扣除前一段趋势后）超过噪声的多少倍才算，越大越不容易误报，噪声由相邻步变化的稳健标准差估计。仅 reset_on_change=true 时使用。
change_min_shift
float		0.2
≥ 0; ≤ 5		最小突变幅度：突变至少是水平的这个比例（0.2 = 20%），很干净的序列上的微小跳变不算。仅 reset_on_change=true 时使用。
quantile_level
float		0
≥ 0; ≤ 0.99		推荐分位数：0 = 点预测（现状）；0.9 等 = 预测「实际值有约 90% 的把握不超过」的线（保形预测：用本算法在这个负载最近几个窗口里的真实误差校准，需要更多历史和时间）。必须大于 0.5。
calibration_windows
int		8
≥ 3; ≤ 50		校准窗口数：用最近多少个历史窗口测本算法的误差；越多越稳，也越慢（每个窗口多跑一次预测）。仅推荐分位数大于 0 时使用。

quantile_level 是 0～1 的分位点，percentile 是 1～100 的百分数，二者不是同一参数。分位校准会额外运行历史预测；增加校准窗口前检查历史与运行预算，覆盖率是评估目标而非保证。

在模块中使用

  1. 保存参数，检查历史窗口、采样步长和预测范围。
  2. 打开模块的“启用预测”；固定算法只运行指定方法，动态算法使用平台已启用的方法。
  3. 先运行滚动回测，通过版本晋升后才会采用；修改影响模型版本的参数后重新回测。
  4. 在仅观察或仅推荐下检查误差、峰值低估、耗时与采用原因，再分别授权准入和副本执行。

历史不足、参数不合法、运行超时或输出无效时，检查算法运行原因；没有合格预测时按模块的固定周期、兜底与保护规则处理。

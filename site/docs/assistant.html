文档/AI 助手

使用指南

AI 助手与 Skill

查询平台状态、使用斜杠技能，导出报告并解读资源变化。

打开 AI 助手

管理员在系统参数中启用 assistant.enabled，并为用户授予 assistant:chat 按钮权限后，右上角显示助手入口。对话在浮动窗口中进行；关闭总开关后入口和窗口都会隐藏。模型连接与技能在“AI 配置”菜单管理。

可以直接提问：“哪些模块需要关注？”“订单服务最近的扩容是否及时？”“平台失联期间 Operator 做了什么？”助手按需读取平台已存的模块、效果报告、伸缩与准入记录，并将结果组织成回答。

用斜杠命令完成常见查询

输入 / 查看可用技能，使用方向键选择，Enter 执行、Tab 补全、Esc 关闭列表。管理员禁用的技能不会出现在可用列表中。

命令用途需要 LLM
/help列出可用技能与参数说明。否
/report生成近 24 小时使用报告，提供文档与 JSON 下载。否
/export导出近 24 小时服务运行状态。否
/tasks查看自己的 AI 定时任务、下次运行与最近结果。否
/attention分析需要关注的模块及原因。是
/outage检查平台失联、离线补报和降级情况。是
/actions [模块]解读伸缩动作，可指定模块。是
/effect <模块>解读指定模块的预测效果。是，模块必填
/admission解读准入决策记录。是

报告与导出直接根据平台记录生成，没有配置 LLM 时也可使用；总开关和访问权限仍需满足。

管理和编写 Skill

在“AI 配置 → Skill 管理”维护技能。内置技能可启用或禁用，提示词只读；需要模型的技能可指定 LLM，未指定时使用默认模型。内置技能不能删除。

自定义技能配置命令、标题、描述、参数模式（不带参数、必填或可选）、模型和提示词。用 {{args}} 引用命令后的输入。例如创建 /review，要求模块参数，并使用以下提示词：

Text
请分析模块 {{args}} 最近 24 小时的预测效果与伸缩记录，区分已知事实、可能原因和缺少的数据。

保存并启用后，聊天命令列表即可使用该技能。指定的模型须可用；技能没有自己的模型时跟随默认连接。

回答范围与操作能力

助手查询已有记录，不修改算法参数、工作负载资源或副本。数值预测仍由预测算法与时序模型计算，执行仍经过平台规则和 Operator。自然语言解释应与对应记录一起阅读。

对话可创建、查看和删除用户自己的 AI 定时任务；这类任务只查询平台并发送回答，不执行资源变更。聊天创建任务只发送到当前用户自己的邮箱。

聊天、技能和导出使用 assistant:chat 权限；LLM 管理、Skill 管理与任务管理分别授权。助手当前可读取平台范围的数据，不能将聊天权限理解为仅能读取个人名下模块。

无法提问时检查什么

  1. 没有入口：检查总开关与聊天权限。
  2. 报告可用但提问失败：检查默认 LLM 是否启用、地址与模型名称、工具调用兼容性及密钥。
  3. 技能未显示：检查是否禁用；需要参数的命令先补齐参数。
  4. 回答缺少信息：核对平台本身是否已有对应时间范围的采集、推荐与执行记录。

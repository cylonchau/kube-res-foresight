USER GUIDE

Backtesting and evaluation

Compare resource forecasts with actual use and understand scores and rankings.

Rolling backtests

Move forecast origins forward through time. Each run uses only history available before that origin, including all additional input metrics. Match windows and horizons to actual operating decisions.

Read resource prediction performance

Accuracy concerns resources such as CPU, memory, and GPU. Replica counts are derived from resource demand and constraints; distinguish them from actual and Ready replicas.

MeasureMeaning and use
WAPETotal absolute error relative to total absolute actual values over the same window.
Peak underestimationThe risk of predicting less than actual high-water demand.
Resource accuracy and scoreRead resource performance, completeness, and protection factors together. Scores do not override execution bounds.
Actual evaluationLink observations to predictions after their target times arrive.

Scores, rankings, and consensus

The rankings page shows current performance and historical changes. Rank helps compare candidates; look-ahead decisions combine available forecasts and confidence rather than simply following the top-ranked method.

Inspect training and run details for window, version, parameters, duration, and reasons. Recheck performance after configuration changes.

Wait for actuals and keep evaluating

Future target times do not yet have actual observations; missing evaluations are not zero error. Continue reviewing resource behavior and outcomes as inputs and workload patterns change.

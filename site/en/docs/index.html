Algorithm reference

Naive

Repeats the latest observation across the horizon. Use it as a basic comparison and to check the data workflow; it cannot anticipate cycles or sudden changes.

Seasonal Naive

Repeats the corresponding observations from the preceding cycle. A seasonal baseline for repeating demand; anomalies in that cycle are repeated too.

EWMA

Smooths recent observations and projects the resulting level. A low-cost candidate for recent demand, without explicit daily seasonality.

Histogram Percentile

Uses a time-decayed historical percentile as a constant future level. Useful for comparing high-water resource sizing, without predicting when a peak occurs.

Random Forest

Fits and averages regression trees on sampled historical features, supporting nonlinear relationships and covariates. More costly than simple statistical methods.

KNN

Finds similar historical windows and follows their subsequent trajectories. Useful for recurring shapes, with limited ability to anticipate patterns absent from history.

Holt-Winters

Models level, trend, and seasonality with additive or multiplicative seasons and optional damped trend. Suitable for cyclic demand with changing levels.

Model service · forecasting and tuning

Calls an external time-series model over HTTP. Configure it in Model management, then choose the module prediction mode. A failed request fails that candidate while other eligible methods continue.

Theta

Combines a smoothed level with half the fitted linear slope, optionally removing seasonality first. A candidate for noisy trends; forecasts are clamped at zero.

MSTL

Separates daily and weekly seasonal shapes and applies Theta to the remainder. This implementation iterates fixed seasonal shapes rather than time-varying LOESS components.

Seasonal Profile

Groups observations by time of day and optionally weekday, then uses a decayed percentile per bucket. Useful for weekday/weekend demand patterns.

Peak Envelope

Builds a rolling-maximum envelope and extrapolates its robust slope. Targets high-water demand rather than averages, such as memory sawtooth patterns and cache growth.

Combination

Combines member forecasts using a stepwise median or recent-error weights. The combination must earn backtest promotion like other candidates.

Ridge AR

Fits linear relationships from lags, optional UTC calendar features, and covariates. A relatively inexpensive machine-learning candidate for stable linear dependencies.

GBDT

Fits successive trees to residuals using lags, calendars, and covariates. Supports squared-error point forecasts or a native quantile objective.

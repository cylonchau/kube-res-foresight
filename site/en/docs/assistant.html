USER GUIDE

AI assistant and skills

Query platform state, use slash commands, export reports, and explain changes.

Open the AI assistant

Enable assistant.enabled in system settings and grant the user assistant:chat. The assistant opens from the top-right button in a floating window. Turning off the global switch hides both the entry and the window. Manage connections and skills under AI configuration.

Ask which modules need attention, whether a service scaled in time, or what the Operator did during an outage. The assistant reads stored modules, effect reports, scaling actions, and admission records as needed to answer.

Use slash commands

Type / to list available skills. Use the arrow keys to select, Enter to run, Tab to complete, and Esc to dismiss. Disabled skills are omitted.

CommandPurposeRequires an LLM
/helpList skills and argument requirements.No
/reportProduce a 24-hour usage report with document and JSON downloads.No
/exportExport the last 24 hours of service status.No
/tasksList your AI scheduled tasks, next runs, and recent results.No
/attentionExplain modules needing attention.Yes
/outageReview outages, queued reports, and degradation.Yes
/actions [module]Explain scaling actions, optionally for a module.Yes
/effect <module>Explain a module's forecasting effectiveness.Yes; module required
/admissionExplain admission records.Yes

Reports and exports are built directly from stored facts and work without an LLM connection. The global switch and access permissions still apply.

Manage and write skills

Use AI configuration → Skill management. Built-in skills can be enabled or disabled; their prompts are read-only and they cannot be deleted. Model-dependent skills can select an LLM; otherwise they use the default.

Custom skills define a command, title, description, argument mode (none, required, or optional), model, and prompt. Reference the argument using {{args}}. For example, create /review with a required module argument:

Text
Analyze the last 24 hours of forecasts and scaling actions for module {{args}}. Separate recorded facts, possible causes, and missing information.

Save and enable the skill to make it available in chat. Its selected model must be available; a skill without one follows the default connection.

Data scope and actions

The assistant queries existing records and does not change algorithm parameters, workload resources, or replicas. Forecasting remains with the forecasting methods, and execution remains with platform rules and the Operator. Read explanations alongside their underlying records.

Chat can create, list, and delete the user's own AI scheduled tasks. These query the platform and send answers without resource changes. Tasks created through chat send only to the current user's own email.

Chat, skills, and exports use assistant:chat. LLM, skill, and task management have separate permissions. Assistant access currently exposes platform-wide data, rather than an owner-only subset of modules.

Troubleshooting

  1. Missing entry: check the global switch and chat permission.
  2. Reports work but questions fail: check the enabled default LLM, endpoint, model name, tool-calling compatibility, and credentials.
  3. Missing skill: check activation and supply required arguments.
  4. Incomplete answer: confirm that collection, recommendations, and execution records exist for the requested window.

Continue with LLM configuration and scheduled tasks and email.

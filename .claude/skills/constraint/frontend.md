# 前端工程约束

项目管理前端在根目录 web。保持现有 Vue/Naive UI 框架、搜索卡片和数据内容布局，品牌使用 kube-resource-fcst。参考最近页面，优先公共组件，禁止每页独立设计。

## 列表与分页

- 标准列表结构：搜索卡片 → 表头操作 → ExpandableDataTable + 分页 → 操作列；检索排序走服务端。
- 分页包含自适应当前视口行数及 30/50/100/200；列设置、可见列和宽度按用户入库，复用 use-table-column-config。
- 必要列支持点击复制；展开箭头、复选框、批量操作和菜单图标沿用公共实现。
- 列标题短，长解释放问号提示；同类列宽一致，一个事实一列。操作横排，NSpace wrap=false，明确 width/minWidth，按钮不竖排。
- 状态用标签，启停放单行及批量操作，不能拿开关直接充状态。
- flex-height 表格父容器必须有明确高度，只有 min-height 可能导致零行；检查不同分辨率及最小高度。

## 搜索、表单和展示

- 中英文 i18n 完整，不残留变量/翻译键。placeholder 指明字段，使用 common.inputField/common.selectField，不用空泛的“请输入/请选择/全部”。
- 搜索复用 web/src/plugins/list-search.ts：NForm class="list-search-form" :model="search"，保留重置/搜索按钮，公共模块 0.3 秒防抖触发。页面不要再写一套自动提交。
- 提示和敏感字段说明放字段旁 ?（IconTooltip）或表头小标签，避免常驻警告横幅/说明卡占布局；实际错误仍需清楚可见。
- 新增/编辑标签在上方（label-placement=top），字段与说明紧凑。多字段使用 edit-modal-wide + NGrid，自适应窄屏；算法参数遵循专属宽屏 schema 编辑要求。
- **禁止标签页（NTabs / NTabPane / 分段标签）切换视图**，页面和弹窗都不用；也不能用"拆成很多页面"代替。一个页面只有一个主视图：搜索卡片 + 一个列表（或一个图表 + 一个列表）。要看别的维度，用搜索条件（例如「评估时间」「时间范围」）、列设置、行内标签、详情弹窗里的分段内容（同一滚动区纵向排列），不增加标签，也不为每个维度新开页面。两个页面用同一个组件、同一个接口时必须合并。
- **全中文**：界面不出现英文状态/模式词（Observe→仅观察，Recommend→仅推荐，Admission→准入，Auto→自动，Bypass→旁路等），状态名统一走 i18n；英文只允许出现在技术名词（PromQL、CPU、WAPE、Kubernetes、算法 ID）里。
- **搜索框**：宽度按内容（短字段短框、名称类中框、关键词长框）；占位符只写字段名，不写"请选择/请输入"，不加括号说明；选项里同一对象的名称只出现一次（模块写模块名，不写"名称(命名空间/工作负载)"）。
- **时间**：所有页面用同一个时间组件（Kibana 风格：一个弹层里有相对时间与固定范围），每页最多一个，禁止并排两个日期框。
- **表格与按钮**：列宽按内容，名称、时间、ID 不留空白；操作按钮统一 tiny（同任务列表）、同样式、同高度：编辑为实心 primary，启用/禁用 warning/success ghost，删除 error ghost，不占多余列宽；适合复制的字段给独立复制图标，点文字不复制。
- **表单**：每个字段旁有问号说明（含义与作用），说明不占主界面。
- **占位与问号的实现**：Naive 默认的“请输入/请选择”已在 `locales/naive.ts` 全局置空，所以搜索卡（标签被隐藏）里每个输入框/下拉必须自带 placeholder=字段名；表单字段统一用 `components/common/help-label.vue`（文案放 `page.formHelp.*`，文案里不写裸 `{}`）；列标题用 `utils/help-title.ts`。个人中心、系统页同样不用标签页，分区并排成卡片。
- **启用/禁用**：所有启用状态用 `components/business/status-select.vue`（两个并排选项），不用开关；用词只有「启用 / 禁用」，不出现「停用」。
- **图例与选择在图表里**：算法的显示/隐藏、数值和误差都放进图表自己的图例（名称 · 最新值 · WAPE），图表上方不再放算法选择框或标签条；预测画在实际之上，图例/提示/表格顺序都是预测在前。
- **查询只有一个入口**：写查询、测试、看结果在同一个表单里完成，测试执行的就是表单当前内容；不弹第二个要求重新输入的对话框，不为同一件事做「自定义/选择映射」两种模式。
- **行内操作**：按钮 tiny，主题同任务列表（编辑实心 primary，其余 ghost），数量固定的操作直接排开，不为 4 个以内的操作做「更多」菜单；列宽按按钮数量设，不留两侧空白。
- **列表里的状态是标签，改状态在表单里**：列表的启用/禁用用同一个 `NTag`（启用绿、禁用灰），不放选择框或开关；表单里用 `status-select.vue`。
- **系统参数是一张表**：LDAP 等参数组都是列表里的普通参数（按分类筛选、逐项编辑，密钥遮盖，保存时整体校验），不另建页面、抽屉或表单。
- **排名依据列默认可见**：页面按某个指标排序或判定时，这一列必须在默认列里（默认可见列数有限，放在第 5 个以内）、有「?」说明、中英文齐全，并有 e2e 检查它真的出现在页面上；新增列别只加进列设置里。
- **图表**（R10 补充）：折线图自带「刷新」按钮，用当前条件重读，不要求再点搜索；图例只写名字、自动换行成几行，不滚动不分页，细节放悬浮提示；序列顺序预测在前、实际在后；数据断开处线也断开（不连线越过缺口），并说明有几处中断；稀疏的点要看得见。
- **默认可见的五列**：默认可见列数有限（系统参数，默认 5），一个页面要让用户一眼看到的事实（如降级记录的触发原因、原配置、目标配置、实际执行结果、发生时间）必须合并到前 5 列里，原来分开的列留作可选；新增页面先量一遍默认可见列。
- **表格留白**：列宽按内容给，多出的宽度由内容列同比例放大直到表格铺满容器（不设倍数上限，列表不能只占 2/3 宽）；选择/展开/操作列保持给定宽度；不要把整块多余宽度倒进一个列；操作列的最小宽度按按钮数设置（`columnMinWidths`），保存过的窄列宽不得遮住按钮。用 `scripts/e2e/table-fit.mjs` 量。
- **时间选择器放最后**：每个搜索区的时间选择器是最后一个字段，触发按钮用普通按钮样式（背景和边框随主题），高度与同行字段一致。
- **模块不写死指标**：模块只关联「指标模板」（模板写一次，变量按模块渲染），动态多行添加、设置权重；不要在模块定义里内置 CPU、内存、副本等指标。
- **表格留白由文字列吸收**：`expandable-data-table` 把多出的宽度交给最宽的文字列，操作列保持按钮需要的宽度。
- **交付前自检（用户反复要求过，逐条核对再说完成）**：不用标签页 · 全中文 · 预测在前实际在后 · 一页一个时间控件 · 搜索框按内容定宽且占位只写字段名 · 表单字段都有「?」 · 复制用独立图标 · 按钮紧凑一行且操作列宽跟着按钮缩（e2e 量过列宽与按钮跨度） · 启用/禁用统一 · 分页可用 · 删除功能先说明数据怎么处理 · 改界面同步后端/库/迁移/e2e。每一条至少要有一个 e2e 检查或截图作证，不能只靠看代码。
- **图表**（参考 Grafana）：不放顶部缩放/下载/刷新按钮，底部时间滑块 ≤ 24px，用"线条类型"（折线/阶梯/K 线）这类明确选项，不用含义不明的开关；预测在前、实际在后。
- 功能分区优先清晰菜单，不把互不相关业务堆在单页里；列表数据分页仍必须保留。
- 页面内一次只放必要的块：图表最多一个，列表最多一个；汇总信息用一行文字或标签，不做大卡片；每个块要有明确高度，分页条必须在卡片和屏幕内（用浏览器量过再交付）。
- 图表分区独立且不重叠，在最小高度检查；弹窗图表测试打开→关闭→再打开的资源释放。

按改动选择 typecheck、单元测试、构建或页面验证；前后端接口同步，分别检查 web 与根仓库状态，按功能整理交付。


## 提交

- **子内容用弹窗，不另开页面**：某个对象的训练记录、快照历史这类“看一个算法/模块的明细”，在发起它的页面上开弹窗（列表 → 详情在同一弹窗内切换，带「返回」），不新增菜单页、不跳转；弹窗内不用标签，详情按“模块与版本 / 结果 / 原因 / 配置”分块纵向排列。
- **历史曲线的缺口**：断开的线用同色虚线连接两端并用底纹标出缺口，图下说明“虚线仅表示缺失位置，未补值”；不得插值或补值；虚线不进提示框。无数据的原因写在图里，不另放卡片。
- **准确度只针对资源**：页面上的准确度是 CPU、内存、GPU 的，不单列副本准确度（副本数由资源推出）；公式见规格第 17.1 节。
